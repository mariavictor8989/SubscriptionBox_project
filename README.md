# FreshBox - Subscription Box Management System 

FreshBox is a comprehensive web-based management system designed for subscription box services. It streamlines the process of user registration, plan selection, and order management through an intuitive administrative dashboard.

##  Key Features
*   **User Authentication System:** Secure sign-up and login functionality for subscribers.
*   **Administrative Dashboard:** A dedicated backend for managing inventory, subscription plans, and user data.
*   **Subscription Management:** Users can browse, select, and manage various subscription plans.
*   **Notification System:** Real-time updates for order status and subscription changes.
*   **Security Focused:** Sensitive database configuration is excluded from version control to prevent credential leakage.

##  Tech Stack
*   **Frontend:** HTML5, CSS3 (Bootstrap), JavaScript.
*   **Backend:** PHP.
*   **Database:** MySQL.
*   **Version Control:** Git & GitHub.
